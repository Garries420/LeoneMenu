# Leone Menu

Tester build **1.0.0-test.16**. Built on Sputnik by Kev and Futurestunt. Leone Menu by Garry.

[Download the tester ZIP](releases/LeoneMenu-1.0.0-test.16.zip). Close GTA, then copy its `moonloader` folder into the folder containing `gta_sa.exe`. Merge the folders and choose **Replace** if prompted. Start SA-MP and type `/leone`.

The repository is private. The `leone-updates` branch holds the prepared menu and alliance-skin feed. See [release feed setup](SETUP.md) for activation and future updates.
